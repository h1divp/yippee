# yippee!

`yippee!` is a simple self-hostable file server and personal cloud. It is inspired by Copyparty and Google Drive. Yippee! is designed to be a single binary with zero external system dependencies using SQLite for metadata and your local filesystem as a source of truth.

> yippee! is super very duper uber in progress, if you want to contribute we would greatly appreciate it, however we would not recommend using it at this time.

### Features (planned)
- Multi-user with dedicated storage spaces
- Easy QR Code/Link based file sharing
- Simple but nice looking UI
- TUS resumable uploads
- Chunkable uploads for large files
- Previews and text editors (for UI based editing)
- And many more! Let us know what you'd like to see (and use)...
